A browser asks a server for files, then turns those files into the page you see. HTML describes the content, CSS describes its appearance, and JavaScript can make it interactive.

RememberA website is a collection of files delivered to your browser over the internet.

HTML (HyperText Markup Language) describes what content means. Elements are written with tags. Use headings in order, links for navigation, and semantic elements such as <main>, <article> and <nav>.

Try itCreate a page with one <h1>, a paragraph, a link and an image with helpful alt text.

CSS (Cascading Style Sheets) controls how HTML looks. A rule pairs a selector with declarations. Learn the box model, then use Flexbox and Grid to arrange content and media queries to adapt it to different screens.

Try itChange a heading’s color, add space around a card, then make a two-column layout stack on a narrow screen.

JavaScript adds behavior to a page. A variable is a named place to keep a value. Use const by default and let when you need to reassign it. Common values include strings, numbers and booleans.

Try itStore your name in a variable and build a greeting with a template string.

Conditions let a program choose a path. An if/else checks whether something is true. Loops repeat work: use a for loop when you know how many times, or a while loop when you need to keep checking a condition.

Try itWrite a loop that counts from 1 to 5 and prints each number.

A function is a named set of instructions you can use again. Parameters are its named inputs; arguments are the values you pass in. A return sends a result back to the caller.

Try itMake a double(number) function that returns its input multiplied by two.

JavaScript often runs directly in a browser. C and C++ are usually compiled: a compiler translates your source code into a program your computer can run. These languages are used for operating systems, games, embedded devices and performance-critical software.

Big ideaDifferent languages, same core skills: break a problem into precise steps and test your solution.

C and C++ ask you to choose a type such as int for whole numbers or char for a character. Types tell the compiler what a value represents. C++ also offers safer, higher-level tools; learn pointers and manual memory management only after the fundamentals.

ConnectionJavaScript variables can hold different kinds of values over time; C/C++ types are declared explicitly and checked by the compiler.

An array stores several values under one name. Each item has an index, usually starting at zero. C uses fixed-size arrays; C++ has useful standard containers such as std::vector. JavaScript arrays can grow and provide built-in methods.

Try itMake a short list of scores and use a loop to calculate their total.

Debugging is the process of finding and fixing a problem. Read the first useful error message, reproduce the issue, inspect values and change one thing at a time. Test normal inputs, edge cases and unexpected inputs.

Good habitBefore coding, describe the problem in plain language and write a tiny example with its expected answer.

Good programs are easier to understand, test, and change. Learn to spot habits that make code fragile, and replace them with small, deliberate steps.

RememberPlan the steps, use clear names, handle unusual inputs, and test what you expect the program to do.

ONE IDEA, MANY LANGUAGES

Learn the idea.
Then learn the syntax.

Once you understand a concept in one language, you can spot it in another. See how the same tiny program looks in JavaScript and C++.

✦

Don’t memorize everything.
Practice reading code, asking questions and changing small things. That’s how programmers learn.

JavaScriptC++A tiny greeting

const name = "Sam";
function greet(person) {
  return `Hello, ${person}!`;
}
console.log(greet(name));
same idea
C++
#include <iostream>
#include <string>
int main() {
  std::string name = "Sam";
  std::cout << "Hello, " << name;
}
