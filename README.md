# Itckari

**CodeQuest** je jednoduchý interaktívny sprievodca základmi programovania pre začiatočníkov. Vedie študenta od tvorby webových stránok až k základným princípom programovania v C a C++.

## Čo projekt obsahuje

- 11 lekcií z HTML, CSS, JavaScriptu, C a C++.
- 15 praktických úloh v každej lekcii vrátane ukážok kódu určených na opravu.
- Výklad základných pojmov, príklady a pseudokód.
- Vyhľadávanie a filtrovanie lekcií.
- Označovanie úloh a lekcií ako dokončených; postup sa ukladá v `localStorage` prehliadača.
- Nápady na malé projekty a stručný prehľad dobrých programátorských návykov.

## Spustenie

Projekt používa čisté HTML, CSS a JavaScript. Nepotrebuje inštaláciu balíkov ani build.

1. Otvor priečinok projektu vo VS Code.
2. Otvor `index.html` priamo v prehliadači alebo ho spusti cez lokálny statický server, napríklad rozšírením Live Server.

## Súbory

- `index.html` — štruktúra stránky a obsah lekcií.
- `styles.css` — rozloženie a vizuálny štýl.
- `script.js` — úlohy, ukážky kódu, filtrovanie a ukladanie postupu.

Postup študenta zostáva uložený iba v danom prehliadači a zariadení; medzi zariadeniami sa nesynchronizuje.
